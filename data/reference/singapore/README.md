# Singapore reference data

- `osm-rail-2026-10-17.json.gz`: a derived OpenStreetMap railway geometry database, © OpenStreetMap contributors, available under [Open Data Commons Open Database Licence 1.0](https://opendatacommons.org/licenses/odbl/1-0/). It retains relation IDs, connected line coordinates and source metadata from the [BBBike Singapore extract](https://download.bbbike.org/osm/bbbike/Singapore/), accessed 17 October 2026. Preparation code is `scripts/prepare_singapore_geometry.py`.
- `2026-10-05.json.gz`: prepared schedules for 5–11 October 2026 and the matched OSM-derived paths. Contains information from **LTA DataMall GTFS Schedule (Train)** accessed **17 October 2026** from [LTA DataMall](https://datamall.lta.gov.sg/content/datamall/en/dynamic-data.html), made available under the [Singapore Open Data Licence version 1.0](https://datamall.lta.gov.sg/content/datamall/en/SingaporeOpenDataLicence.html). The OSM-derived geometry and resulting derived spatial database are available under **ODbL 1.0**; the underlying LTA schedule data retains its Singapore Open Data Licence terms. Preparation code is `scripts/prepare_singapore_replay.py`.

These files and the retained OSM geometry provide the derived data used in the application. Data attribution also appears alongside the replay map. No API keys, signed download URLs, logos or official map artwork are included. SunTrain is independent of LTA, SMRT, SBS Transit, OpenStreetMap and BBBike.

Times come from a schedule snapshot, not observed vehicle movements or a complete archive of historical disruptions. The geometry is a separately dated geographic reference. One anomalous Sunday NS trip has empty path legs; its timetable is retained. Passenger counts and Singapore buses are not included.
